# social-media-backend
A REST API for a social media application, built with Java and Spring Boot.

The goal of this project is to build a backend for a social media platform, starting with user management and gradually adding social features.

## Current Features

- User management.
- User creation, retrieval, update, and deletion.
- PostgreSQL database integration.
- Global exception handling.

## Tech Stack

- **Java** — Programming language.
- **Spring Boot** — Backend framework.
- **Spring Data JPA** — Database access and persistence.
- **PostgreSQL** — Relational database.
- **Maven** — Dependency management and build tool.
